## 更新内容

- 为 Rolithax Schema 3 提供能力查询和实例目录识别。客户端可以定位 MCDR 配置、插件目录和 Minecraft 子目录。
- 启用 Schema 插件时，客户端可查询服务器插件、模组或 MCDR 插件的版本。元数据无法确认时，可以在用户同意后运行管理员登记的只读版本检查。
- 增加独立的宿主机任务 Worker。宿主机管理员按用户和实例登记可运行的任务，客户端每次运行前需确认。Rolithax 中心的「宿主机任务」开关默认关闭。

## 兼容性和下载

插件要求 MSLX Daemon 1.7.3 或更新版本，`MinSDKVersion` 为 `1.7.3`。插件与 Worker 均使用 .NET 10。

- `Rolithax.Plugin.DaemonExtensions.dll` 安装到 Daemon 数据目录下的 `Plugins/`，也可下载含安装说明的同名 ZIP。
- 启用宿主机任务或只读命令版本检查时，根据 Daemon 所在系统下载 `Rolithax.Schema.Worker-win-x64.zip` 或 `Rolithax.Schema.Worker-linux-x64.zip`，按包内 `README.md` 部署。
