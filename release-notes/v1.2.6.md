## 兼容性

最低要求为 MSLX Daemon 1.7.3，插件声明的 `MinSDKVersion` 为 `1.7.3`。

## 更新内容

- 修复扩展 API 开关和 Daemon 对外地址保存。Rolithax 中心根据服务端返回的实际状态刷新，设备配对关闭后会显示对应提示。
- 修复 HTTP 面板中的二维码原文复制。浏览器拦截自动复制时，可直接选择原文手动复制。过期二维码的复制按钮会禁用。
- 优化 Rolithax 中心的桌面和手机布局，设备表格可在窄屏内横向滚动。
- 分支构建增加前端类型检查、插件编译和回归测试。

## 下载

- `Rolithax.Plugin.DaemonExtensions.dll` 可直接安装到 Daemon 的 `Plugins/` 目录。
- `Rolithax.Plugin.DaemonExtensions.zip` 包含插件 DLL 和安装说明。
